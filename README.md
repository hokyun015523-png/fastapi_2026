# 급여 / 비급여 의약품 연령금기 비교 분석 (금기연령층)

## 프로젝트 소개

- 식품의약품안전처 연령 금기 의약품 데이터를 이용하여 필요한 데이터를 추출하고, 전처리 및 파생컬럼을 생성한 후  postgreSQL에 저장하는 프로젝트 입니다.
---
## 데이터 출처 
- 공공데이터 포털 : https://www.data.go.kr/tcs/dss/selectFileDataDetailView.do?publicDataPk=15089531#tab-layer-file

---
## 사용 데이터 

- 원본 데이터에서 컬럼을 추출하여 사용했습니다.

    | 컬럼명 | 설명 |
    |-------|------------|
    | 제품명 | 의약품 이름|
    | 급여구분 | 급여 / 비급여 여부 |
    | 특정 연령 | 연령금기 기준 |
    | 특정연령 단위 | 세 / 개월 |
    | 업체명 | 제약회사 |

---
## 파생 컬럼
- 분석을 위해 새로운 컬럼을 생성 했습니다.

    | 컬럼명 | 설명 |
    |-------|---------------------------------------|
    | 금기연령층 | 영유아, 소아, 청소년, 고령자로 분류 |


    - 예) 

        | 특정연령 | 금기연령층 |
        |----------|------------|
        | 3 | 영유아 |
        | 12 | 소아 |
        | 18 | 청소년 |
        | 65 | 고령자 |

---

## 데이터

1. 선택한 데이터(CSV 또는 API)를 적절한 인코딩으로 읽어 원본 데이터를 확인

2. 데이터 특성에 맞게 필요한 전처리 또는 구조 변환 수행

3. 금기연령층 파생 컬럼 생성 


4. 처리된 데이터를 PostgreSQL bigdatatestdb(데이터베이스이름)의 수집 테이블에 저장완료
